# 🛍️ Fashion Store App (Flutter)

A modern **e-commerce mobile application** built with Flutter and Firebase.
This app allows users to browse products, add items to cart, place orders, and manage their profile securely.

---

## 🚀 Features

### 🔐 Authentication

* User Registration & Login (Firebase Authentication)
* Secure Logout
* Persistent login session

### 🛒 Shopping

* Browse products by category
* Product details screen
* Add to cart functionality
* Update quantity / remove items

### 💳 Checkout

* Enter delivery details (name, address, phone)
* Calculate total price
* Place orders

### 📦 Orders

* Save orders to Firebase Firestore
* View order history

### 👤 User Profile

* Display user name & email
* Logout functionality

---

## 🛠️ Tech Stack

* **Frontend:** Flutter (Dart)
* **Backend:** Firebase

  * Firebase Authentication
  * Cloud Firestore
